Aplicación Web de Objetos Perdidos y Encontrados – Universidad Don Bosco
Descripción

Se propone desarrollar BackToMe, una aplicación web para la Universidad Don Bosco (UDB) que permita centralizar, registrar, buscar y gestionar objetos perdidos y encontrados dentro de las instalaciones de la institución.

Los usuarios podrán registrar objetos indicando información como categoría, descripción, fecha, características y lugar donde fueron perdidos o encontrados. La aplicación permitirá realizar búsquedas y filtros por categoría y ubicación, mostrar posibles coincidencias y enviar solicitudes para recuperar un objeto.

Además, contará con un proceso de validación del propietario, gestión de solicitudes, registro de la devolución, historial y estados de los objetos, facilitando un proceso más organizado y seguro para la recuperación de pertenencias dentro de la universidad.

El sistema contará con dos roles de usuario: usuario general y administrador, cada uno con permisos diferenciados según sus funciones.

También se integrará una API externa de mapas y geolocalización, que permitirá asociar los reportes con los lugares donde ocurrieron, visualizar las ubicaciones y analizar las zonas de la universidad donde se presentan mayores cantidades de reportes.
